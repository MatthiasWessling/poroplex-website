# Poroplex website

Multi-page public website for Poroplex, built as a static Vite project.

**Live website:** https://matthiaswessling.github.io/poroplex-website/

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The generated site is written to `dist/`.

## Pages

- Home
- Technology
- Impact
- About
- Contact
- Privacy

## Content and confidentiality

The `Background Info/` directory contains confidential source material and is excluded through
`.gitignore`. Do not force-add that directory or copy internal budgets, chemical recipes, timelines,
partner information, IP strategy, or unvalidated performance claims into public pages.

Public copy intentionally:

- describes the technology as being in development;
- avoids quantitative commercial and performance claims;
- separates intended benefits from validated results;
- does not claim a finalized company form or legal status.

## Before public launch

- Complete and legally review the privacy notice and required German *Impressum*.
- Confirm permission for any photography or partner logos before adding them.
- Confirm the final public contact email.
- Review all technology, patent, PFAS/BPA, and performance language with the founders.
- Configure the chosen hosting provider and update the privacy notice accordingly.
